# 雀魂 成績スタジオ

牌譜屋（雀魂牌譜屋）のスクリーンショットを読み込むと、YouTube の動画で使う図とサムネイルを PNG で作るアプリです。

- **動画用（1920×1080）**: 結果まとめ / 変わった・変わらなかった / 100戦あたり / 順位の割合 / 項目ごとの変化 / 平均順位の推移 / 成績表
  - どの図も、見出しにデータから作った結論の一文（例:「トップが6.4pt増え、ラスが4.8pt減った」）が入ります
  - **「動画で保存」** で、数字が「前」から「後」へ動く約4秒の動画（MP4、対応していないブラウザでは WebM）を保存できます
- **サムネイル（1280×720）**: 平均順位 / 段位 / 順位の割合
- **台本の下書き**: 図の内容に沿ったナレーションの文章を自動で作ります
- **データの保存・読み込み**: 読み取った成績をファイルに保存して、別の PC でも続きから作れます
- 見た目は「ダーク」「ライト」「グリーンバック（動画編集で背景を抜く用）」から選べます
- 「前」と「後」の差が偶然で出る確率も計算して表示します

画像の文字読み取り（OCR）はブラウザの中だけで行います。画像や成績がどこかに送られることはありません。

## はじめて使うとき（Windows）

1. [Node.js](https://nodejs.org/ja) の LTS 版をインストールする
2. コマンドプロンプト（または PowerShell）で次を実行する

   ```
   git clone -b test https://github.com/ToooOOmuch/Claude-Apps-01.git C:\app
   cd C:\app
   npm install
   npm run dev
   ```

3. 表示された `http://localhost:5173/` をブラウザで開く

2回目からは、`C:\app` の **`起動.bat` をダブルクリック** するだけで、アプリが起動してブラウザが開きます（デスクトップにショートカットを置くと便利です）。PC で Claude Code を使っている場合は、`C:\app` で「起動」と言うだけでも起動します。最新版にするときは、先に `git pull` と `npm install` を実行してください。

## 使い方

1. 牌譜屋で自分のプレイヤーページを開き、「基本」タブで **成績の表と順位分布の円グラフが両方写る** ようにスクリーンショットを撮る
   - 画面下の「期間」ボタンで期間を指定してから撮ります（期間の日付も読み取ります）
   - 「学ぶ前」と「学んだ後」の2枚が最低限必要です。期間を細かく分けて何枚か撮ると、推移のグラフが細かくなります
2. アプリに画像をドロップ（クリックして選択、Ctrl+V で貼り付けも可）
3. 読み取った数字を確認し、違っていれば直す。期間の名前（例: 学ぶ前）もここで付けます
4. 比べる「前」と「後」の期間、見出しの文字を選ぶ
5. 右側の図を「PNG保存」か「動画で保存」で保存する（録画中は、そのタブを表示したままにしてください）
6. 「台本の下書き」タブで、ナレーションの下書きをコピーできます

### 読み取りについて

- 順位の割合は、円グラフの扇形の角度から測り、円の中の数字も読めればその値を使います（誤差は ±0.1% 程度）
- 平均順位は順位の割合から計算した値と照らし合わせ、合わなければ計算値に置き換えます
- 読み取れなかった項目や、確認してほしい点はカードの上に表示します。「画像から読み取った文字を見る」で OCR の生の結果も見られます

## 開発

```
npm run dev        # 開発用サーバー
npm test           # テスト
npm run typecheck  # 型チェック
npm run build      # dist/ に本番用ファイルを出力（npm run preview で確認）
```

- `npm install` のときに、OCR 用のファイル（言語データ・WASM）を `public/ocr/` にコピーします（`scripts/copy-ocr-assets.mjs`）
- `test/local/` は手元のスクリーンショットでの確認用で、Git には含めません

### フォルダ構成

| 場所 | 内容 |
|---|---|
| `src/lib/parse.ts` | OCR の文章から成績の項目を取り出す |
| `src/lib/pie.ts` | 円グラフを見つけ、順位の割合を角度から測る |
| `src/lib/extract.ts` | スクリーンショット1枚の読み取り全体の流れ |
| `src/lib/compare.ts` | 偶然で出る確率などの計算 |
| `src/render/slides.ts` | 動画用の図とサムネイルの描画 |
| `src/render/insights.ts` | 図の見出しにする結論の一文を作る |
| `src/render/animate.ts` | 「前」から「後」へ動くアニメーションと録画 |
| `src/lib/script.ts` | 台本の下書きを作る |
| `src/render/theme.ts` | 色（テーマ） |
| `src/App.tsx` | 画面 |
